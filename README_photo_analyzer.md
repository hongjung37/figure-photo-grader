# 사진 EXIF + Gemini 평가기

사진 파일에서 촬영에 필요한 EXIF만 추출하고, Gemini의 구조화 출력(JSON Schema)을 사용해 구도·조명·색감·촬영 기술·최종 점수(각 10점 만점)와 범주별 미학 태그를 평가한 뒤 SQLite에 저장하는 단일 이미지 CLI입니다.

## 개인정보 처리

GPS 위치, 촬영 시각, 소유자/코멘트, MakerNote, 카메라·렌즈 일련번호는 업로드 이미지와 SQLite에 포함하지 않습니다. Gemini로 보내는 이미지는 새로 인코딩하며, 허용 목록의 카메라/렌즈 모델 및 조리개(F-number), 셔터(ExposureTime), ISO, 초점거리 등 촬영 설정만 EXIF에 다시 넣습니다. 같은 안전한 설정은 API 요청의 텍스트에도 함께 전달되어 촬영 기술 평가에 활용됩니다. Interactions API 요청은 `store=False`로 생성합니다. 다만 사진 픽셀 자체는 분석을 위해 Google Gemini API로 전송되며 Google의 API 데이터 처리 정책이 적용됩니다.

## 피규어 촬영 세부 유형 및 프롬프트 분기 (--category)

피규어 사진 내부에서도 촬영 의도에 따라 평가 기준이 달라지도록 **4가지 세부 유형 분기**를 지원합니다.

- `auto` (기본값): 사진을 분석하여 아래 4개 유형 중 가장 적합한 것을 **자동 판별**하고 해당 전용 잣대로 심사합니다.
- `macro` (접사/디테일): 피규어 얼굴, 눈동자 데칼, 의상 질감, 무기 디테일 초근접 촬영
  - *특화 심사 기준*: 눈동자 데칼의 초정밀 칼초점, 코/귀가 날아가지 않는 적절한 매크로 심도, 미세 먼지/도색 마감 통제, 번들거리는 반사광(핫스팟) 억제
- `snap` (일상/야외 스냅): 자연광 아래 야외 출사, 여행 동행, 카페 등 실제 일상 환경과 피규어의 상호작용
  - *특화 심사 기준*: 자연광(역광/측광)의 창의적 활용, 실제 환경과 피규어의 자연스러운 스케일감 조화, 계절감 및 일상적 스토리텔링, 자연스러운 여백
- `staging` (스튜디오 연출/디오라마): 배경지, 다각도 조명 세팅, 디오라마 세트, 이펙트 파츠를 활용한 극적 연출
  - *특화 심사 기준*: 다각도 조명(키/필/림라이트)의 드라마틱한 입체감과 명암비, 디오라마와 피규어의 정교한 비율, 역동적인 포징, 클리어 파츠 투과광
- `general` (일반 피규어 촬영): 전신/상반신 단정 스탠다드 포토
  - *특화 심사 기준*: 피규어 원형의 왜곡 없는 렌즈 화각과 프레이밍, 단정한 배경 분리, 자연스러운 피부톤 밸런스

```powershell
# 1. 자동 유형 판별 (기본값)
python .\photo_analyzer.py "sample.jpg"

# 2. 접사/디테일 전용 심사 기준으로 강제 지정
python .\photo_analyzer.py "sample.jpg" --category macro

# 3. 야외 스냅 사진 폴더 일괄 분석
python .\photo_analyzer.py ".\photos\" --category snap --workers 4
```

## 실행 모드 및 모델 티어 (Lite / Standard / Pro)

분석기는 피규어 및 캐릭터 모델 사진(Figure Photography)의 완성도를 전문적으로 비평하도록 최적화되어 있습니다. 작업 목적에 맞춰 세 가지 모델 티어 중 하나를 선택할 수 있습니다.

- `--tier lite`: `gemini-3.1-flash-lite` (기본값) — 빠르고 가벼운 대량 분류 및 스크리닝용
- `--tier standard`: `gemini-3.5-flash-lite` — 균형 잡힌 표준 화질 평가용
- `--tier pro`: `gemini-3.8-flash` — 고화질 심층 비평 모드

```powershell
# 1. 단일 사진 기본 분석 (Lite)
python .\photo_analyzer.py "F:\photos\sample.jpg"

# 2. 고화질 정밀 심층 비평 모드 (Pro)
python .\photo_analyzer.py "F:\photos\sample.jpg" --tier pro

# 3. 모델명을 직접 지정할 수도 있습니다.
python .\photo_analyzer.py "F:\photos\sample.jpg" --model "gemini-3.8-flash"
```

## 폴더 일괄 분석 (Batch Mode)

단일 파일뿐만 아니라 **폴더 경로**를 지정하면 폴더 내 모든 사진을 병렬로 일괄 분석하고 비교 요약 보고서를 자동 생성합니다.

```powershell
# 폴더 내 모든 사진 일괄 분석 (워커 2개 기본)
python .\photo_analyzer.py "F:\photos\figure_set\"

# 4개 병렬 워커 + Pro 티어로 하위 폴더까지 일괄 분석
python .\photo_analyzer.py "F:\photos\figure_set\" --tier pro --workers 4 --recursive

# 개별 보고서 폴더 및 비교 요약 HTML 경로 지정
python .\photo_analyzer.py "F:\photos\" `
  --report-dir "F:\reports\" `
  --summary-html "F:\reports\comparison.html"
```

일괄 분석 완료 시 터미널에 진행률과 점수 요약이 출력되며, `<폴더>/comparison.html`에 반응형 비교 표가 생성됩니다.

지원 입력 형식은 JPEG, MPO, PNG, WEBP입니다. MPO는 첫 프레임을 분석 대상으로 사용하고, 허용된 촬영 정보만 남긴 표준 JPEG로 재인코딩합니다. 너무 큰 이미지는 업로드 한도에 맞춰 리사이즈/재인코딩합니다. 표준 출력에는 파이프 처리 가능한 JSON 결과만, 저장 완료 메시지는 표준 오류에 출력합니다.

## 저장 구조

`photo_analyses` 테이블에 파일명, SHA-256, 표시 방향 기준 크기, 형식, 모델, 개인정보를 제외한 `exif_json`, 검증된 `analysis_json`, UTC 저장 시각을 저장합니다. 미학 태그는 `analysis_json.aesthetic_tags`에도 포함되며, 집계·검색을 위해 허용 어휘를 `photo_tag_catalog`, 사진별 태그를 `photo_analysis_tags`에 정규화해 저장합니다. 같은 사진을 다시 분석하면 새 행이 추가됩니다.

태그 범주는 시점, 구도·공간, 포즈·시선, 분위기, 피사체-배경 관계, 빛 표현, 색조 인상, 이야기 암시의 8가지입니다. 시점 어휘에는 정면·측면·후면·사선과 로우/하이 앵글 등이 포함됩니다. 각 범주는 이미지에서 확인되는 태그만 최대 3개 기록하며, 해당되지 않거나 근거가 부족하면 빈 배열로 둡니다.

## 점수 평가 척도 및 비평 기준

지나치게 긍정적이거나 후한 점수 인플레이션을 방지하고, 사진의 객관적인 완성도와 한계를 날카롭게 분석하도록 엄격한 채점 기준과 장단점 구분 방식을 적용합니다.

- **점수 척도 기준 (10점 만점)**:
  - **9.0 ~ 10.0: 프로사진작가 및 전문가급** — 상업 화보, 사진전시회 또는 전문 포트폴리오 수준의 완성도. 빛·구도·기술의 완벽한 통제와 독창적 연출. 결함이나 아쉬움이 없는 마스터피스.
  - **8.0 ~ 8.9: 매우 우수** — 상급 사진가 및 하이아마추어 수준. 주제가 명확하고 완성도가 높으며 시각적 완성도가 뛰어남. 사소한 아쉬움만 존재.
  - **7.0 ~ 7.9: 우수** — 기본기가 탄탄하고 잘 찍힌 준수한 사진. 안정적인 면이 있으나 구도 정리나 빛의 활용, 설정 등에서 분명한 단점이나 개선 여지가 공존함.
  - **5.0 ~ 6.9: 보통 (일반 스냅)** — 일상적인 스냅사진 수준. 구도 불안정, 노출 과부족, 배경 분산, 초점의 아쉬움 등 일반적인 한계가 다수 보임.
  - **5.0 미만: 개선 필요 (기초 미흡)** — 초점 이탈, 심각한 흔들림, 노출 실패 등 기초적인 기술적 결함이 큰 사진.

- **장점 및 단점 구분 출력**:
  - 구도, 조명, 색감, 촬영 기술의 세부 메모는 각각 `[장점]`과 `[단점]` 문단을 명확히 분리하여 서술합니다.
  - 종합 평가(최종 근거)는 장점과 단점을 균형 있게 반영하여 해당 점수를 부여한 냉정한 이유를 설명합니다.
  - 주요 장점(`strengths`)과 단점 및 개선점(`improvements`) 목록을 각각 분리하여 실질적인 촬영 피드백을 제공합니다.

- **피규어 눈동자/페이스 초점 핀 정밀 판정 (`focus_status`, `focus_notes`)**:
  - 피규어 사진의 성패를 가르는 눈동자(아이 데칼) 및 안면 조형의 초점 상태를 5단계로 정밀 심사합니다.
  - 별도의 API 재호출 없이 기존 단일 분석 요청에 통합되어 **추가 토큰 소모가 없습니다.**
  - `완벽 칼초점`: 눈동자 데칼의 경계면과 반사광이 타협 없이 극도로 선명함
  - `미세 앞핀`: 눈동자보다 앞쪽(앞머리 끝, 코끝, 무기)에 초점 맺힘
  - `미세 뒤핀`: 눈동자보다 뒤쪽(귀, 머리 뒤편, 어깨)에 초점 맺힘
  - `초점 이탈`: 피규어 얼굴 전반에 핀이 맞지 않거나 흔들림
  - `판별 불가`: 극단적 심도/블러 등
  - 판정 결과는 HTML 보고서, 웹 대시보드 갤러리 카드/상세 모달, Excel 시트에 모두 뱃지 및 메모로 표시됩니다.

- **시각적 워터마크/하단 프레임 촬영 설정 감지 (`detected_camera_settings`)**:
  - WebP 변환 등으로 파일 내부 EXIF 메타데이터가 누락되었더라도, 사진 하단 테두리나 워터마크(라이카 프레임 등)에 카메라 기종, 조리개 F값, 셔터속도, ISO, 렌즈명 등이 인쇄되어 있다면 이를 자동으로 감지하여 촬영 기술 심사에 반영하고 대시보드 및 보고서에 표시합니다. 불확실하거나 워터마크가 없는 일반 사진에서는 환각을 방지하기 위해 엄격히 `null`로 유지됩니다.

## Excel로 분석 결과 관리

기존 사진 분석 명령과 SQLite 저장 흐름은 그대로 사용할 수 있습니다. pandas와 openpyxl로 분석 기록을 보기 좋은 `.xlsx` 파일로 내보내고, Excel에서 수정한 평가와 태그를 ID 기준으로 기존 DB에 반영할 수 있습니다. 기존 워크북에 태그 열이 없으면 빈 태그로 처리해 가져올 수 있습니다.

```powershell
# 기본 DB 전체 내보내기: 프로젝트 폴더에 photo_analyses.xlsx 생성
python .\photo_excel_manager.py export

# 저장 경로를 직접 지정할 수도 있습니다.
python .\photo_excel_manager.py export --output "F:/photos/photo_analyses.xlsx"

# Excel에서 편집·저장한 뒤 SQLite로 반영
python .\photo_excel_manager.py import "F:/photos/photo_analyses.xlsx"

# 다른 SQLite DB 사용
python .\photo_excel_manager.py export --db "F:/data/photo_reviews.sqlite3" --output "F:/data/photo_analyses.xlsx"
python .\photo_excel_manager.py import "F:/data/photo_analyses.xlsx" --db "F:/data/photo_reviews.sqlite3"

# 범주별 태그 사용 빈도 확인
python .\photo_excel_manager.py tags
```

워크북에는 분석 기록 표와 사용 안내 시트가 들어갑니다. 점수(0~10), 초점 상태/분석, 평가 메모, 최종 평가, 강점·개선점, 8개 범주의 태그, 검토 상태, 사용자 메모를 수정할 수 있습니다. 태그는 범주별 셀에서 줄바꿈으로 나누고, 안내 시트에 기재된 허용 어휘 중 범주당 최대 3개를 입력합니다. 검토 상태에는 `미검토`, `확인 필요`, `검토 완료` 목록이 제공됩니다. ID와 파일 정보는 표시용이며, 가져올 때는 DB의 해당 정보를 덮어쓰지 않습니다.

Excel 내보내기는 DB를 읽기 전용으로 열어 스키마나 데이터를 수정하지 않습니다. 가져오기는 기존 ID의 분석 내용·태그·검토 상태·사용자 메모만 갱신합니다. 새 행을 DB에 추가하거나 DB 행을 삭제하지 않으며, ID 중복·미등록 ID·필수 열 누락·잘못된 점수·허용되지 않은 태그·잘못된 검토 상태가 하나라도 있으면 전체 반영을 취소합니다. SQLite 트랜잭션으로 반영하므로 검증에 실패해 일부 행만 바뀌지 않습니다. 처음 가져오면 검토 필드와 태그 카탈로그·사진별 태그 테이블이 추가될 수 있으며, 기존 분석 기록은 유지됩니다.

## Culling & Review Web 대시보드

피규어 사진을 편리하게 선별(Culling)하고 A/B 컷을 1:1로 비교하며, 일괄 업로드 및 라이트룸 보정값 제안까지 원스톱으로 처리할 수 있는 반응형 웹 대시보드입니다.

```powershell
python .\photo_dashboard.py
# 포트나 DB를 변경하여 실행할 수도 있습니다.
python .\photo_dashboard.py --port 8080 --db .\photo_analysis.sqlite3
```

브라우저에서 `http://localhost:8080`으로 접속하면 다음 기능을 사용할 수 있습니다:
- **다중 사진 및 폴더 일괄 업로드 (신규)**:
  - **📁 폴더 통째로 선택 (`webkitdirectory`)**: 폴더를 선택하면 하위 폴더 내 모든 사진을 브라우저가 자동 재귀 탐색하여 일괄 분석
  - **📸 여러 사진 선택 (`multiple`)**: `Ctrl+A`로 수십 장을 한 번에 선택하여 일괄 큐 전송
  - **폴더/파일 드래그 앤 드롭**: 탐색기에서 사진 폴더를 드롭존에 놓으면 내부 사진을 자동 수집
  - **실시간 프로그레스 바(Progress Bar)**: 실시간 진행률(%), 현재 분석 중인 파일명, 각 완료 건의 점수/유형 안내
  - **내결함성(Fault-tolerance)**: 일부 사진 실패 시 건너뛰고 계속 진행, 완료 후 대시보드 자동 갱신
- **갤러리 뷰**: 등급별 필터(`우수`, `매우 우수`, `보통`), 유형별 필터, 점수순 정렬, 미학 태그 뱃지, 초점 핀 뱃지(`🎯 완벽 칼초점`), 상세 모달
- **눈동자/데칼 2.4배 확대 돋보기(Zoom Pan)**: 상세 모달에서 사진을 클릭하면 마우스 위치를 따라 2.4배 확대되어 초점 핀과 디테일 마감을 즉시 검증
- **키보드 단축키 초고속 Culling**: `←` / `J` (이전 사진), `→` / `K` (다음 사진), `Space` (확대 줌 토글), `Esc` (닫기)
- **1:1 Culling 비교 뷰**: 사진 A와 B를 나란히 놓고 점수 차이, `[장점]`과 `[단점]`을 대조하여 A컷 선별
- **연사(Burst) 자동 그룹핑 및 Best Pick 선별 (B-1)**:
  - 지각 해시(dHash, 64-bit) 알고리즘 기반으로 유사 구도·포즈의 연사 사진 자동 그룹핑 (무의존성 순수 PIL 고속 연산)
  - 그룹 내 점수, 초점 핀 완성도, 선예도를 종합 평가하여 **`👑 Best Pick (1위)`** 자동 선정
  - 탈락한 컷(B컷)에 왜 1등을 놓쳤는지 명확한 탈락 사유(`초점 핀 열세`, `조명/노출 밸런스 열세`, `종합 완성도 차이` 등) 자동 태깅
  - 대시보드 갤러리 상단에서 **`[👑 Best Pick만 보기]`**, **`[🗂️ 연사 묶어보기 (Stack)]`** 필터 모드 지원
  - 상세 모달 상단에 연사 묶음 배너 및 **그룹 내 사진 즉시 전환 썸네일 네비게이션** 탑재
- **대시보드 상세 모달 2분할 레이아웃 & 평가 코멘트 컴팩트 뷰**:
  - **좌측**: 원본 사진 뷰어 + 2.4배 돋보기 + Adobe Lightroom 보정 슬라이더 + SNS 규격 크롭/다운로드 박스 배치
  - **우측**: 세부 평가 요소(구도/조명/색감/기술) 10점 만점 **요약 바 차트(그래프)** + 세부 코멘트 컴팩트 카드 (스크롤 최소화)
- **Adobe Lightroom 추천 보정 슬라이더 수치 제안 (C-1 온디맨드 & 캐싱)**:
  - 상세 모달에서 `[🛠️ 라이트룸 보정 수치 제안 받기]` 버튼 클릭 시 해당 1장에 대해 온디맨드 호출 (토큰 절약)
  - 노출(EV), 대비, 하이라이트(번들거림 억제), 섀도우(암부 복원), 텍스처, 화이트밸런스/틴트 가이드 및 피규어 맞춤 리터칭 팁 제시
  - 분석 결과는 SQLite(`lr_advice_json`)에 영구 캐싱되어 재호출 없이 즉시 로드
- **소셜 미디어(Instagram · X) 최적화 크롭 & AI 캡션 제안 (D-2 온디맨드 & 캐싱)**:
  - 인스타그램(세로피드 `4:5`, 정방형 `1:1`) 및 X/트위터(가로 타임라인 `16:9`, 모바일 세로 `3:4`) 규격별 최적 크롭 영역 제안
  - 대시보드 모달에서 비율 버튼 클릭 시 원본 사진 위에 **실시간 크롭 프레임(3분할 가이드 그리드) 오버레이** 표시
  - 브라우저 Canvas 기반 **`[✂️ 이 비율로 잘라 다운로드]`** 원클릭 고화질 크롭 이미지 저장 지원
  - 피규어 특화 감성 캡션 및 다국어 해시태그(#피규어, #figurephotography 등) 원클릭 복사
  - 요청 시에만 온디맨드로 호출하여 토큰 낭비를 원천 차단하며 SQLite(`sns_advice_json`)에 영구 캐싱
- **Lightroom / Capture One XMP 원클릭 내보내기**: 상단 `📥 라이트룸 XMP 내보내기` 버튼으로 사진 옆에 `.xmp` 사이드카 파일 자동 생성 (1~5 별점 및 색상 라벨 즉시 동기화)


## Lightroom / Capture One XMP 사이드카 연동 (`--xmp`)

사진 분석 시 `--xmp` 옵션을 주면, 원본 사진 파일 옆에 Adobe 표준 `.xmp` 사이드카 파일이 자동 생성됩니다.

```powershell
# 단일 사진 분석 시 XMP 동시 생성
python .\photo_analyzer.py .\test_photo\fig1.webp --xmp

# 폴더 일괄 분석 시 전체 XMP 자동 생성
python .\photo_analyzer.py .\test_photo --xmp
```

- **별점(Rating) 매핑**:
  - 9.0~10.0: ★★★★★ (5성, Purple)
  - 8.0~8.9: ★★★★☆ (4성, Blue)
  - 7.0~7.9: ★★★☆☆ (3성, Green)
  - 5.0~6.9: ★★☆☆☆ (2성, Yellow)
  - 5.0 미만: ★☆☆☆☆ (1성, Red)
- 라이트룸 또는 캡처원에서 폴더를 동기화하면, AI가 매긴 별점과 장단점 설명, 미학 키워드 태그가 그대로 반영되어 초고속 선별 작업이 가능합니다.

## HTML 분석 결과 화면

분석 점수와 해설을 브라우저에서 확인하고 싶다면 분석 명령에 `--html` 경로를 추가합니다. 평소처럼 JSON은 표준 출력으로 반환되고 SQLite에도 저장되며, 별도로 단독 실행할 수 있는 HTML 보고서가 생성됩니다. 보고서에는 최종 점수, 구도·조명·색감·촬영 기술 점수, 초점 핀 뱃지(`🎯`), 해설, 강점·개선점, 범주별 미학 태그 및 분석용 이미지 미리보기가 들어갑니다.

```powershell
python .\photo_analyzer.py "F:/photos/sample.jpg" --html "F:/reports/photo_analysis_report.html"
```

생성된 `.html` 파일을 Edge나 다른 브라우저에서 열면 됩니다. 보고서는 이미지 미리보기와 스타일을 안에 포함하므로 오프라인에서도 열 수 있습니다.
